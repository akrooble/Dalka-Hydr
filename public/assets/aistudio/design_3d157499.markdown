## Brand & Style

The design system establishes a high-precision, utilitarian aesthetic suited for institutional procurement, talent acquisition, and enterprise bidding workflows. Combining corporate rigor with contemporary SaaS agility, the visual language balances crisp structural boundaries with luminous electric indigo highlights.

Targeting enterprise hiring managers, procurement officers, and specialized talent, the experience prioritizes clarity, immediate legibility, and effortless data evaluation. Rather than relying on heavy textures or ornamental depth, visual structure is achieved through crisp 1px borders, subtle container distinctions, and deliberate micro-interactions that convey operational trust and speed.

## Colors

The palette revolves around a core electric indigo (`#6366F1`), providing energetic visual guidance for primary calls-to-action, active statuses, and focused interface states. The primary dark neutral (`#0F172A`) commands headings and high-contrast structural chrome, while a slate gray spectrum (`#64748B` through `#F8FAFC`) anchors secondary text, borders, and contextual backdrops. 

A tertiary emerald green (`#10B981`) is integrated specifically to support contract lifecycle statuses, open tender alerts, and verified badge treatments. 

When presenting light-mode surfaces, background tiers use crisp white (`#FFFFFF`) layered against cool slate tinted canvas (`#F8FAFC`), bordered with subtle hairline strokes (`#E2E8F0`). High-density data tables and cards maintain contrast ratios above 4.5:1 for body copy and 3:1 for graphical elements, meeting WCAG AA standards.

## Typography

The typographic scale uses a single, robust grotesque sans-serif to reinforce utilitarian efficiency and cross-device consistency. Headings employ slightly tightened tracking (`-0.015em` to `-0.02em`) to enhance cohesion at large scales, preventing loose visual anchors in dense enterprise grids.

Body copy defaults to standard regular tracking and generous line heights (1.4x to 1.5x) to maintain scannability through long RFP specifications and candidate profiles. All metadata tags, status indicators, and column labels utilize medium-to-semibold weights with subtle positive letter spacing to maintain distinct silhouette readability across smaller sizes.

## Layout & Spacing

The layout model uses a responsive 12-column grid system capped at a maximum container width of `1280px` for standard analytical workflows, expanding to fluid boundaries on operational dashboards. Column gutters adapt from `1.5rem` on desktop views to `1rem` on compact tablet and mobile viewports.

Spacing relies on an eight-point rhythmic scale:
- **Mobile (< 768px):** 4 columns, `1rem` horizontal page margins, vertical component stacking. Filter drawers slide over content rather than occupying layout space.
- **Tablet (768px - 1024px):** 8 columns, `1.5rem` page margins. Secondary contextual metadata collapses into segmented view toggles.
- **Desktop (1024px+):** 12 columns, `2rem` page margins, supporting simultaneous dual-pane inspection (such as job listing lists alongside live procurement details).

## Elevation & Depth

Visual hierarchy avoids heavy drop shadows, instead using crisp borders and layered tonal surfaces to produce structured depth:

- **Flat / Ground Layer:** The page canvas rests on `#F8FAFC`.
- **Level 1 (Cards, Modules, Tenders):** Pure `#FFFFFF` surfaces bounded by crisp 1px strokes in `#E2E8F0`. Depth is articulated through subtle ambient diffusion (`0 1px 3px 0 rgba(15, 23, 42, 0.04)`).
- **Level 2 (Dropdowns, Flyouts, Popovers):** Elevated `#FFFFFF` surfaces with a 1px border (`#CBD5E1`) and a low-opacity, dual-layer contact shadow (`0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`).
- **Level 3 (Modals, Overlays):** Framed surfaces supported by a semi-transparent slate wash (`rgba(15, 23, 42, 0.6)`) utilizing an ambient shadow (`0 20px 25px -5px rgba(15, 23, 42, 0.12)`).

For translucent glassmorphic components (sticky headers, floating filter summaries), interfaces use a backdrop blur of `12px` combined with a semi-opaque background (`rgba(255, 255, 255, 0.85)`) and a hairline lower border.

## Shapes

The design system implements a controlled, compact radius scale based on `roundedness: 1` (`0.25rem` / `4px` base radius). This produces clean geometric corners that preserve layout alignment and avoid the visual bulk of heavy border radii.

- **Base Controls (`rounded`):** Checkboxes, form inputs, tooltips, and table cell badges use `0.25rem` (4px).
- **Surface Enclosures (`rounded-lg`):** Cards, modal panels, filter modules, and data grid containers use `0.5rem` (8px).
- **Large Panels (`rounded-xl`):** Dedicated slide-out drawer sheets and high-level platform modules use `0.75rem` (12px).
- **Pill Exceptions:** User avatars, live numeric notification pips, and discrete status indicators retain fully circular or pill shapes (`9999px`) to immediately distinguish contextual tags from clickable rectangular actions.

## Components

### Buttons
- **Primary:** Background `#6366F1`, text `#FFFFFF`, 1px border `transparent`. Hover: `#4F46E5`. Active: `#4338CA`. Height: `38px` (inputs match button heights for linear alignment).
- **Secondary:** Background `#FFFFFF`, text `#0F172A`, 1px border `#E2E8F0`. Hover: `#F8FAFC` and border `#CBD5E1`.
- **Tertiary / Ghost:** Background `transparent`, text `#475569`. Hover: background `#F1F5F9`, text `#0F172A`.

### Status Badges & Chips
- **Procurement Status:** Height `24px`, padding `0.125rem 0.5rem`, border radius `9999px`. 
  - *Active / Open:* Background `rgba(99, 102, 241, 0.08)`, border `1px solid rgba(99, 102, 241, 0.25)`, text `#4F46E5`.
  - *Awarded / Verified:* Background `rgba(16, 185, 129, 0.08)`, border `1px solid rgba(16, 185, 129, 0.25)`, text `#059669`.
  - *Draft / Closed:* Background `rgba(100, 116, 139, 0.08)`, border `1px solid rgba(100, 116, 139, 0.2)`, text `#475569`.
- **Interactive Filter Chips:** Removable tags with trailing dismiss icons, structured with `rounded` corners (4px) and subtle slate outlines.

### Form Inputs & Selectors
- **Text Inputs:** Height `38px`, background `#FFFFFF`, border `1px solid #E2E8F0`, typography `body-md`, placeholder color `#94A3B8`. Focus state applies a crisp stroke (`#6366F1`) paired with a 2px outer outline (`rgba(99, 102, 241, 0.15)`).
- **Checkboxes & Radios:** `16px x 16px` boundaries, `rounded` 4px corner for checkboxes, border `1.5px solid #CBD5E1`. Checked state transitions background to `#6366F1`.

### Cards & Listings
- **Tender & Job Cards:** `#FFFFFF` background, `0.5rem` border radius, bordered with `1px solid #E2E8F0`. Padding uses `space-md` (`1rem`) internally, featuring structured tabular metadata (submission deadlines, budget figures, location tags) divided by hairline dividers (`#F1F5F9`). Hover state elevates border color to `#CBD5E1` without shifting card position.

### Data Tables & Marketplace Grids
- **Table Headers:** Background `#F8FAFC`, border-bottom `1px solid #E2E8F0`, typography `label-md` in `#64748B`.
- **Table Rows:** Alternating hover highlights (`#F8FAFC`), padded `0.75rem 1rem`, anchored by clean horizontal borders (`1px solid #F1F5F9`).
